# Install 

Template includes a script that will help you to configure a fresh project.

Script will ask you for project name and will update all necessary files with it.
Backend and frontend dependencies will be installed and configured.
Git repository will be initialized and first commit will be made.


[Bootstrap script](https://code.area17.com/-/snippets/78) is available as snippet to automatically download a fresh template copy and run the setup script.

```shell
sh -c "$(curl -fsSL https://code.area17.com/-/snippets/78/raw/main/bootstrap.sh)"
```


But if you prefer, you can download the repository manually and run the following command:
```shell 
$ sh install.sh
```
